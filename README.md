# Inter_ 2024 Webサイト ソースコード

公開サイト: [https://24.idd-master.com/](https://24.idd-master.com/)

## 概要

`Inter_` は、卒業展示イベント企画の情報発信を目的としたレスポンシブ Web サイトです。

イベント情報、プログラム内容、スケジュール、会場情報、ビジュアルコミュニケーションを、シンプルで軽量なシングルページ構成の中で表現しています。視覚的な印象、モーション、レスポンシブレイアウト、スムーズな操作感を重視して制作しました。


## 主な特徴

- レスポンシブ対応のシングルページサイト
- イベント / 展示情報のビジュアル表現
- カスタムカーソルとモーション演出
- スケジュール・会場情報の表示
- 日本語 / 英語を含む情報設計
- 静的サイトとしての軽量な公開構成
- 保守しやすいフロントエンド構造

## 技術スタック

- React
- TypeScript
- Vite
- CSS Modules
- CSS Animation
- Static Site Deployment
